# StoYangu

Online stores for Kenyans who sell physical products on social media.

**Pricing:** KES 5,000 setup · KES 300/month maintenance  
**Offer:** Video Yangu, Store Yangu  
**Email:** info@stoyangu.com

## Make it yours
Read **`OWNERSHIP_GUIDE.md`** (full non-technical steps).  
Run **`supabase-setup.sql`** inside your Supabase SQL editor.  
Copy env names from **`.env.example`** into Vercel.

## Stack
Vite + React + TypeScript + Tailwind · Supabase · Vercel
